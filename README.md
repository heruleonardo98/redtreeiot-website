# RedTree IoT · Website

Website company profile RedTree IoT (Medan): https://redtreeiot.netlify.app

- `site/` – file website yang dipublikasikan Netlify (HTML/CSS/JS biasa, tanpa build).
- `brand/` – logo dan daftar kredit foto.
- `CLAUDE.md` – panduan untuk Claude (termasuk cloud session): desain, bahasa, aturan konten.

## Mengubah website
1. Ubah file di `site/` (lewat Claude, cloud session, atau langsung di GitHub).
2. Simpan ke branch `main` (atau setujui pull request).
3. Netlify otomatis mempublikasikan dalam ±1 menit.
